# Primer v2 Implementation Plan

> Agentic workers: use executing-plans to implement task by task.

**Goal:** Mevcut hikâyeye ölçülebilir, küçük ONNX modeli ve dürüst teslim kanıtı eklemek.
**Architecture:** Tarayıcıda WASM çıkarımı; Python oracle; yerel, rızalı CSV toplama. Sentetik pilot ve gerçek kullanıcı sürümü ayrılır.
**Tech Stack:** React/Vite, ONNX Runtime Web, sklearn/skl2onnx, Python ONNX Runtime, Cypress.
**Spec:** `spec.md`, `model-policy.json`; kullanıcının Ödev 7 talimatları.

## Global constraints

- balanced_accuracy ≥0.75, recall ≥0.70, fark <1e-4; seed=42.
- Gerçek oturum uydurulmaz. Yayında ≥15 tam gerçek oturum gerekir.
- Önceki hikâye, manuel öğretmen ve 12 regresyon korunur.
- Mevcut kök Git deposu değil; mevcut dosyalar yerinde korunur, otomatik commit/push yapılmaz.

## Review focus

- Aynı oturumun train/test'e sızması; grup ayrımı testi.
- Hedef veya mevcut karar sonucunun özellik olması; yalnız geçmiş davranışları kullan.
- Rızasız veri ve serbest metin dışa aktarımı; CSV şema testi.
- Model bozukluğu veya sözleşme uyuşmazlığı; oyuna devam testi.
- Sentetik ölçümü gerçek başarı gibi sunma; yayın kapısı testi.

Interface: policy ordered float32[1,6] → probabilities[1,2]; class 1 support.
- [ ] Eğitim kapısı ve oturum sızıntısı için önce başarısız test.
